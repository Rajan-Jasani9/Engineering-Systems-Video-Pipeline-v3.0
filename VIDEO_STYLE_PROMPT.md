# Video Style Prompt

Use this prompt when generating supporting bitmap assets or visual references. For full video production rules, read `VISUAL_GUIDE.md` first.

Create a punchy kinetic typography explainer for engineering systems.

Use a strict black-and-white visual language: matte black background, white chalk/marker strokes, white interface labels, grey unspoken words, and active words inverted into black text on a white hand-drawn sticker. Avoid color accents.

The background should feel like a living system-design whiteboard: doodly boxes, dashed arrows, service nodes, database cylinders, queues, retry loops, cache labels, consistency contracts, and small lucide-style engineering icons. Keep all visuals monochrome, hand-drawn, slightly imperfect, and continuously drifting or pulsing so the video never feels static.

Before each major section of the video, generate or animate a compact system diagram that matches the spoken idea: APIs, queues, stores, ledgers, regions, retries, idempotency keys, fanout, and consistency boundaries. Use these as supportive background motion while the karaoke typography remains the primary focus.

Generated images should be used sparingly. Prefer React/CSS/SVG/lucide visuals for normal scenes. If a generated bitmap is needed, it must look like it belongs on the same dark engineering whiteboard and remain monochrome.
